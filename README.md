# 🔱 umaa (উমা) — Immersive Durga Puja Music Experience

> ঢাকের তালে, কাশফুলের হাওয়ায়… মা আসছেন।  
> Live at **[umaa.tech](https://umaa.tech)**

---

## 🌟 Highlights & Features

- 🎥 **Cinematic Background**: Seamlessly looping fullscreen Durga Puja video with subtle ambient Shiuli phool & Kashphul fluff particles.
- ⏳ **Live Countdown**: Days, Hours, Minutes, and Seconds countdown to Maha Sasthi (Durga Puja 2026) in Bengali typography.
- 🍎 **Apple iOS Liquid Ultra-Glass Design**: Frosted acrylic depth, specular highlight sheens, and responsive glass tiles.
- 🤖 **Google Pixel Dynamic Wave Scrubber**: Mathematical 60FPS continuous sinusoidal squiggly progress bar in Pixel Mint Green with real-time seeking.
- 🔽 **Minimizable Floating Glass Dock**: One-click minimize to a floating bottom dock featuring rotating vinyl artwork and live equalizer soundwave animation.
- 🎶 **Curated Puja Playlist**: 17 iconic Bengali Durga Puja celebration songs from classic Agomoni to energetic Dhak beats.
- 📱 **Mobile & PWA Ready**: Optimized for touch ergonomics (44px+ hit targets), safe area insets, and iOS/Android "Add to Home Screen".
- ⚡ **Vercel Production Optimized**: Complete with native dynamic favicon (`/icon.svg`), `manifest.webmanifest`, `robots.txt`, `sitemap.xml`, and security headers.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS Glassmorphism
- **Animations**: [Framer Motion](https://www.framer-motion.com/) & Vector SVG
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio Engine**: YouTube IFrame Audio Streaming API

## 🚀 Getting Started

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/INdrajit88/umaa.git
cd umaa
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

---

## 🌐 Deployment on Vercel

1. Import this repository into [Vercel](https://vercel.com/new).
2. Deploy with standard Next.js settings.
3. In **Project Settings > Domains**, connect **`umaa.tech`**.
